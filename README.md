# Kalender Frankrijk

Eén kalender met alle data die ertoe doen voor Nederlanders en Belgen in Frankrijk: feestdagen en schoolvakanties in beide landen, de fiscale kalender (particulieren, ondernemers, Nederland), betaaldagen van pensioenen en uitkeringen, verkiezingen, seizoen en mijlpalen. Met rubrieken, een eigen iCal per rubriek, een kleine JSON-API en het blok "Vandaag in het kort" voor de dagelijkse nieuwsbrief van Nederlanders.fr.

Een uitgave van Communities Abroad. De bestaande Fiscale kalender Frankrijk op Infofrankrijk blijft bestaan als rubriek van deze kalender.

Stand: ontwerpfase (2 november 2026). Zie `docs/BRIEFING.md` en, zodra goedgekeurd, `docs/ONTWERP.md`.
