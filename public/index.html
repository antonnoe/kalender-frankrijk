Kalender Frankrijk

Alle data die ertoe doen voor Nederlanders en Belgen in Frankrijk, met een eigen agenda per rubriek. Een uitgave van Communities Abroad.

  • /api/vandaag: de regels voor "Vandaag in het kort"
  • /api/items: alle data, met filters van, tot, rubriek, doelgroep, toon_in
  • /api/status: hoe vers zijn de bronnen
  • /api/rubrieken: de tien rubrieken met hun beeld
  • /ical/alles.ics, /ical/<rubriek>.ics, /ical/fiscaal-particulier.ics: agenda's om te abonneren

Uitleg voor beheerders: zie de README op GitHub.
